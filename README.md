## 👨‍💻 Presentación

Soy Software Engineer especializado en el desarrollo **Backend con el ecosistema .NET**, enfocado en la construcción de APIs REST robustas, integraciones empresariales avanzadas e implementación de lógica de negocio compleja. Cuento con amplia experiencia trabajando en la arquitectura y optimización de bases de datos relacionales, consumo e integración de ERPs (como Odoo), facturación electrónica e incorporación de soluciones de Inteligencia Artificial para la estimación de procesos de producción. 

Mi enfoque abarca el ciclo completo del software: desde la captura de requerimientos y el diseño de modelos relacionales, hasta la refactorización eficiente de código en producción y la automatización empresarial.
