## 👨‍💻 Presentación Profesional

Soy Senior Software Engineer centrado en la **arquitectura y desarrollo Backend en C# y .NET**. Cuento con una sólida trayectoria diseñando e implementando sistemas distribuidos, APIs REST escalables, microservicios e integraciones complejas (ERPs, Facturación Electrónica e IA aplicada a estimación de procesos).

Mi enfoque principal abarca la aplicación de **Clean Architecture, Domain-Driven Design (DDD), patrones de diseño async/non-blocking**, así como la estructuración y optimización avanzada de bases de datos relacionales SQL Server y PostgreSQL.
